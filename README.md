# Laboratório de Projeto de Pesquisa

Ferramenta interativa para orientar a construção do **Projeto de Pesquisa Teológico-Ministerial**, em dez etapas: tema (com relevância para a atualidade), título, contextualização, delimitação, justificativa, problematização, objetivo geral, objetivos específicos, obras de referência e caminhos para a fundamentação teórica.

Elaborado pelo **Prof. Alexandre Fonseca do Prado Beloni**.

**Acesse:** https://alexandrebeloniimw-cmyk.github.io/laboratorio-projeto-pesquisa/

## Recursos

- Orientações, perguntas orientadoras e exemplos didáticos em cada etapa
- Análise das respostas, com identificação de fragilidades e sugestões de melhoria
- Verificação do tema no acervo de trabalhos já aprovados, para evitar temas repetidos
- Rascunho salvo no próprio aparelho, com opção de baixar e abrir o arquivo do rascunho
- Visualização do projeto completo e exportação em PDF (padrão ABNT)

> Este laboratório não substitui a sala de aula, seja ela física ou virtual. A orientação do professor orientador é a que prevalece.
